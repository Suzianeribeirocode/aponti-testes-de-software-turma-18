# Atividade Avaliativa — Teste Exploratório e Usabilidade

## 1. Cite 5 pontos que você exploraria livremente no sistema

1. **Processo de login e autenticação**
   - Verificar login com credenciais válidas e inválidas, recuperação de senha e mensagens de erro.

2. **Navegação entre as telas**
   - Avaliar se os menus, botões e links funcionam corretamente e permitem uma navegação intuitiva.

3. **Preenchimento de formulários**
   - Testar campos obrigatórios, validação de dados, limites de caracteres e mensagens de validação.

4. **Pesquisa e filtros**
   - Verificar se a busca retorna resultados corretos e se os filtros funcionam conforme esperado.

5. **Operações principais do sistema**
   - Executar as funcionalidades mais importantes (como cadastro, consulta, edição ou exclusão de registros) para identificar falhas inesperadas.

---

## 2. Cite 5 possíveis problemas de usabilidade que poderiam existir

1. Interface confusa ou com excesso de informações.
2. Botões e menus difíceis de localizar.
3. Mensagens de erro pouco claras ou sem orientação.
4. Tempo de resposta elevado durante as operações.
5. Layout que não se adapta corretamente a diferentes dispositivos ou tamanhos de tela.

---

## 3. Explique por que esses problemas impactam o usuário

Esses problemas prejudicam a experiência do usuário porque dificultam a realização das tarefas, aumentam o tempo necessário para concluir operações e podem causar erros ou frustração. Uma interface confusa reduz a produtividade, mensagens pouco claras dificultam a correção de erros, lentidão desestimula o uso do sistema e problemas de adaptação em diferentes dispositivos comprometem a acessibilidade. Como consequência, o usuário pode perder a confiança no sistema e deixar de utilizá-lo.
